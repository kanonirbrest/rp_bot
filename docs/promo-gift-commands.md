# Промокод клуба (раздел «Специальные предложения»)

| Команда / действие | Что делает |
|--------------------|------------|
| `/offers` или кнопка «Специальные предложения 💝» | Открывает акции клуба и вкладку «Дом Рождества» |
| Кнопка «Сгенерировать индивидуальный промокод» | Выдаёт персональный промокод `DR-XXXXXXXX` (нужен номер телефона; один код на человека) |
| Вкладка «Дом Рождества» | Скидка 10% на «Дом Рождества», сайт domrp.by, срок по 17.01.2027 |
| `/certificates` / «Подарочные сертификаты 🎁» | Только текст про подарочные сертификаты в кассе — **без промокода** |
| `/revokepromo DR-…` | *(админ)* Отключает промокод «Дома Рождества» по коду. `NR-` тоже можно отключить, новые коды «Небо.Река» не выдаются |
| `/reissuepromo <id>` или `/reissuepromo DR-…` | *(админ)* Новый активный промокод «Дома Рождества» |
| `/userpromo <id>` или `/userpromo DR-…` | *(админ)* Код и статус «Дома Рождества» |
